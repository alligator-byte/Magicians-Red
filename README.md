# Magician's Red
## Abstract
In past I've completed units based around agile web development and building tools for real world contexts for clients or for projects. In order to practice this skill I've begun developing a prototype for a web application based around tarot card reading. The title "Magician's Red" is inspired off of a TV show that I'm quite fond of, with this inspiration motivating me to challenge myself my coding this app with limited assistance.  
## Planned Functionality
I'm currently aiming to have the core python logic complete the following tasks:
- draw three cards at random
- assign meanings based on the order in which they are drawn in
- print all information to the user
- output thumbnails of the cards linked to what was drawn

As for website design so far, I currently plan to have site work without a user login - then will later a develop a verison in which a user my login in and share the card drawing from the day.
